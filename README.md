# CUECRAFT

Учебный full-stack сайт-каталог бильярдных киев и аксессуаров для портфолио.
Стек: PHP 8.3+, PDO SQLite, HTML, CSS и JavaScript без сборщика.

Работающий сайт: https://cuecraft.infinityfreeapp.com/

## Что уже работает

- Каталог с фильтрами и карточками товаров.
- Окно с подробностями товара.
- Форма заявки.
- PHP API, которое сохраняет заявки в SQLite.
- Вход в админ-панель, блокировка после пяти неверных паролей и учёт остатков.
- Редактирование цен, количества и статусов заявок.
- Демо-оплата с успехом, отказом, отменой и демонстрационным подтверждением.
- Перевод по реквизитам с ручной проверкой продавцом.
- Помощник по правилам и необязательный адаптер локальной Ollama.

## Структура папок

```text
templates/        HTML-страницы
static/css/       стили CSS
static/js/        JavaScript
static/images/    фотографии товаров
index.php         главный PHP-сервер и API сайта
.htaccess         настройка Apache для адресов /admin и /api/...
payments.php      демонстрационные платежи и перевод
advisor.php       подбор товаров и адаптер Ollama
config.php        загрузка локальных настроек
config.example.php пример без секретов
data/             локальная база заявок
```

## Первый запуск

1. Скачайте репозиторий, откройте терминал в его папке.
2. Проверьте `php -v` и наличие `PDO`, `pdo_sqlite` в выводе `php -m`.
3. Скопируйте `config.example.php` в `config.local.php`.
4. Запустите локальный сервер:

```sh
php -S 127.0.0.1:8000 index.php
```

Откройте http://127.0.0.1:8000. Остановка: Ctrl+C. Каталог и база создаются
автоматически. PHP должен иметь право записи в `data/`.
Встроенный сервер предназначен только для разработки.

Альтернатива: поместить проект в `www/billiard-cues` Laragon, запустить Apache
и открыть http://localhost/billiard-cues/. Apache должен поддерживать
`mod_rewrite` и `.htaccess`. Live Server не исполняет PHP.

## Настройки

Админка находится по адресу `/admin`. В новой копии вход отключён, пока
не задан `CUECRAFT_ADMIN_PASSWORD_HASH`. Создайте уникальный длинный пароль
и вычислите его хеш локально:

```sh
php -r "echo hash('sha256', trim(fgets(STDIN))), PHP_EOL;"
```

Введите пароль и нажмите Enter (ввод виден в терминале). Поместите результат
в `config.local.php`. Переменные окружения имеют приоритет над этим файлом.
Учебная реализация использует SHA-256; для рабочего магазина требуется
переход на `password_hash` / `password_verify`.

Для перевода задайте `CUECRAFT_TRANSFER_IBAN` и `CUECRAFT_TRANSFER_RECIPIENT`.
CVV, срок действия карты и банковский пароль не нужны.
Без реквизитов посетитель должен уточнить их у продавца.

Онлайн-оплата — демонстрация без списания денег и банковского чека.
Настоящий платёжный провайдер пока не подключён: см. [PAYMENTS.md](PAYMENTS.md).
Помощник без Ollama работает по правилам. Для нейросети отдельно установите
Ollama, скачайте модель и задайте `CUECRAFT_OLLAMA_MODEL`; нужен PHP cURL.
Подробнее: [ASSISTANT.md](ASSISTANT.md).

## Где лежат заявки

При первом запуске появится файл `data/cuecraft.db`.
Это локальная SQLite-база данных с таблицей `orders`.

## Проверка PHP

PHP-файл проверяется командой `php -l index.php`. Перед переносом он был
проверен на отдельной копии базы: каталог, вход админа, заявка и изменение
остатков работают.

Перед публикацией проверьте синтаксис всех PHP-файлов через `php -l`,
каталог, тестовую заявку, демо-оплату и вход администратора.

# Подготовка к GitHub

1. Проверьте `git status --short` и `git diff --cached`.
2. Создайте пустой репозиторий GitHub, например `cuecraft`, без README и лицензии.
3. Выполните команды, подставив свой адрес:

```sh
git add .
git commit -m "Prepare CUECRAFT portfolio project"
git remote add origin https://github.com/YOUR_USERNAME/cuecraft.git
git push -u origin main
```

Потребуется вход в GitHub. Если origin уже задан, сначала проверьте
`git remote -v`. Не отправляйте config.local.php, data/, базы и сессии.
Открытые телефон и email в HTML — контактные данные автора: перед публичным
репозиторием убедитесь, что готовы оставить их видимыми.

Лицензия пока не выбрана. Проверьте права на изображения перед повторным
использованием; публичный репозиторий сам по себе не даёт разрешение на всё.

## Перед запуском рабочего магазина

- PHP-хостинг, HTTPS, резервное копирование базы.
- Сильный пароль и password_hash/password_verify, CSRF для админских изменений.
- Платёжный провайдер с проверкой подписанных webhook и сумм заказа.
- Проверка конкурирующих заказов, резервов и возвратов.
- Актуальные контакты, тексты, условия доставки и обработки персональных данных.

Публикация учебных исходников не означает готовность принимать реальные платежи.

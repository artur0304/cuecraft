# Временный бесплатный сервер

Для портфолио можно использовать InfinityFree: на бесплатном плане заявлены
PHP 8.3, SQLite через PDO, `.htaccess`, HTTPS-сертификаты и загрузка файлов
через File Manager или FTP. Возможности и ограничения тарифа проверяйте перед
регистрацией: [официальная страница InfinityFree](https://www.infinityfree.com/).

## Что загрузить

Загрузите содержимое проекта в папку `htdocs`:

```text
index.php, payments.php, advisor.php, config.php, config.example.php
.htaccess, .gitattributes
templates/, static/
```

Не загружайте `data/`, `config.local.php`, тестовые базы, `.git/`, старые
Python-файлы и локальные логи. Сервер создаст `data/cuecraft.db` сам при
первом открытии, если PHP разрешено создавать файлы.

## Частные настройки на сервере

Скопируйте `config.example.php` в `config.local.php` через File Manager и
впишите свой хеш пароля администратора. Для портфолио оставьте оплату в режиме
`demo`; реальные банковские реквизиты на публичный учебный сайт не добавляйте.

После загрузки откройте адрес субдомена. Проверьте каталог, тестовую заявку,
демо-оплату и `/admin`. Если появляется ошибка 500, временно включите журнал
ошибок в панели хостинга и проверьте, что доступны `PDO` и `pdo_sqlite`.

Ollama на бесплатном PHP-хостинге не запускается рядом с сайтом: помощник
останется в режиме правил. Для настоящей модели нужен отдельный сервер с Ollama
или внешний AI API и серверный ключ.

## Важно

Бесплатный сервер подходит для демонстрации портфолио. Перед реальными заказами
нужны HTTPS, резервные копии, политика обработки данных, проверенный платёжный
провайдер и отдельные рабочие реквизиты.
